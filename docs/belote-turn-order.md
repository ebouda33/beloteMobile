# Règle canonique de rotation

Cette règle est canonique pour le projet et ne doit pas changer sans mise à
jour explicite du moteur, des tests et de la documentation.

Ordre de table anti-horaire, appliqué partout:

1. `Vous`
2. `Adversaire droite`
3. `Partenaire`
4. `Adversaire gauche`

Cette rotation s'applique à:

- la distribution;
- la parole;
- le jeu de la carte;
- la rotation du donneur entre les manches.

Conséquences opérationnelles:

- le donneur distribue en commençant par le joueur suivant dans cet ordre;
- la parole commence par le joueur à droite du donneur;
- le premier pli commence par ce même joueur;
- si tous les joueurs passent deux fois, la nouvelle donne repart avec le
  donneur suivant dans cet ordre.
